# redesign-v2-2026-09-01 — Work Plan

> 依据：`docs/design-language-v2.md`（已获用户批准）。
> 目标：把 music-os 从「抽象行星宇宙」重设计为「黑场舞台 + 封面光源 + 动态色彩 + 两态接管」。

## 范围原则

- **技术形态不改**：单 Canvas + CameraRig、AudioEngine/metrics、Zustand、IPC/SQLite/Provider 边界、数据模型。
- **设计语言唯一权威**：`docs/design-language-v2.md`，实施中任何分歧以该文档为准。
- **不复制 Mineradio 素材/代码**（GPL-3.0 + 视觉版权）。
- 每阶段独立 commit，失败可单独 revert。

## P0 — 视觉基座（tokens/globals）

- `styles/tokens.css`：重写为 v2 系统（`--mo-bg:#050507`、三档灰 ink、`--mo-accent` dynamic 占位、玻璃/字阶/动效 token、`--mo-warm`）。
- `styles/globals.css`：去蓝调（bg/scrollbar/selection 跟随新 token）、焦点环改 accent、动效 keyframes 收敛。
- 验收：`build:renderer` 绿；无蓝调残留（grep `#0A1220`/`#8DBBFF` 于 styles 下应无）。

## P1 — Home「舞台」重做

- `hooks/useDominantColor.ts`：封面主色提取（Image + canvas 采样，降采样 8x8 取平均/最饱和色），返回 `{color, isDark}`；无封面回退 `energyTarget` 映射。
- `ui/HomeOrbital.tsx` 重写为「舞台」：
  - 中央偏左大封面发光物（`track.artworkUrl`，280px，身后 `blur(80px)` 光晕；无封面唱片兜底）。
  - 显示级曲名 30px/300 + 歌手 14px 灰；点击 = 播放/暂停；无曲目 → 载入提示 + 文件选择。
  - 左下 3 枚发光小物体：曲库 / 记忆 / 情绪滤镜（悬停浮现 micro 标签）。
  - 右下安静时钟（mono，弱灰）。
  - 删除：轨道环、行星、核心 pill、`CoreVisualDom` 引用、环境染色 radial-gradient。
  - `--mo-accent` 由 `useDominantColor` 驱动（未播放态白）。
- `App.tsx`：`onCoreClick` 相关逻辑随之简化；移除 HomeOrbital 的 onCoreClick 依赖。
- 验收：`build:renderer` 绿；首屏无轨道/行星；`#audio-session-debug` 哨兵保留。

## P2 — 播放态接管

- `worlds/CoverParticleField.tsx`：提级为播放舞台主角——播放态 opacity 目标 0.3-0.45（现 0.55+energy 逻辑调整）、尺寸/呼吸微调、`currentSpace` 从 'home' 放宽到 'home' + 'library'（播放时曲库背景也有粒子呼吸）；未播放回退极淡星尘。
- `ui/AudioDock.tsx`：升级为完整玻璃控制条——保留胶囊玻璃，新增：
  - 频谱层：播放态 30 条 hairline（`<canvas>` 或 div），用 `useAudioStore.metrics` rAF 绘制，置于曲名与进度之间。
  - 进度 hairline 发光 thumb（已有）加 accent 流动（`--mo-accent`）。
  - 播放键/封面块/时间全部跟随 accent 动态色。
- 验收：播放时粒子幕明显浮起、控制条频谱走动、accent 随封面主色变化。

## P3 — 空间收敛

- `worlds/LibraryGalaxyWorld.tsx` → 封面场：真实封面网格（`tracks` 的 `artworkUrl`，12px 间距，1:1，悬停微亮 + 曲名浮现），点击 → 右侧玻璃详情面板；无封面唱片兜底；空态弱文字。
- `worlds/MemoryFieldWorld.tsx`：暖金细光时间线（`--mo-warm` 发光点，最常听最亮，悬停玻璃小签，点击回放）。
- 删除 `MoodSpaceWorld.tsx`、`VisualizerWorld.tsx` 独立空间；情绪滤镜并入首页小物体（复用 `store/mood` persist）。
- `store/runtime.ts`：`currentSpace` 类型收敛为 `home | library | memory`。
- `App.tsx`：移除 mood/visualizer 渲染分支；TopBar 精简（删历史/用户弹层，只留 brand/标题/搜索）。
- 验收：`currentSpace` 三态；无 mood/visualizer 残留引用（grep）。

## P4 — 打磨与验证

- 转场：`CameraRig` 简化（home/library/memory 三态转场，600ms fade+scale）。
- 空态/恢复态：恢复会话提示、载入失败提示对齐新视觉。
- 全量：`build:renderer` + `build:electron` + `smoke:electron` 绿；人工桌面验收。

## Commit 策略

- P0: `refactor: v2 设计系统视觉基座（tokens/globals）`
- P1: `feat: 首页重设计为黑场舞台（封面光源+动态色彩）`
- P2: `feat: 播放态舞台接管（粒子幕+控制条频谱+accent流动）`
- P3: `refactor: 空间收敛（封面场/记忆轨迹/移除mood-visualizer）`
- P4: `chore: v2 打磨与全量验证`
- 仅包含本计划文件；README/dist/out/tsbuildinfo 脏文件不纳入。

## 风险

- **封面提取色不稳定**（深色/多色封面）：`useDominantColor` 需做亮度/饱和度启发式，失败回退 energyTarget。
- **删除 mood/visualizer 影响 smoke 哨兵**：`scripts/electron-smoke.cjs` 若断言这些空间，需同步更新（仅哨兵字段，不改契约）。
- **粒子幕性能**：保持现有 COUNT 不变（56x56），只调 opacity/size，不做新几何。
